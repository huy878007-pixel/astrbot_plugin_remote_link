# 云信互联 · 子分类路由与提示词流水线设计（v0.1.0）

> 状态：已实现并随 v0.1.0 正式版发布。本文档是 0.2.0/0.3.0 内部迭代期间的结构性改版设计基线。

## 1. 理解总结

- **要做什么**：把智能调度从"LLM 自由选工作流"改为「一级分类 + 子分类配置表 + 二级提示词分析」的确定式流水线；每个子分类可独立配置默认工作流、LLM 提供商/模型、提示词模板；同时整体重做 Web 控制台与本地 GUI。
- **为什么**：用户不信任 LLM 识别多模块工作流；希望工作流单一化（每个工作流只干一件事）；子分类（图生图/多图生视频等）用规则判断更可靠；提示词质量由专门 LLM + 每类模板保证。
- **给谁用**：单用户本地部署（云端 AstrBot + 本地 ComfyUI）。
- **关键约束**：单一流程优先；规则判定子分类；每子分类独立 LLM/模板；全链路兜底不中断；产物直发 QQ。
- **明确不做**：不做多模块工作流自动识别；不新增第三方依赖；不改变隧道协议。

## 2. 假设（已确认/默认）

- 多图生视频工作流使用 `__IMAGE_1__`/`__IMAGE_2__`… 多图片入口占位约定（已支持）。
- 图生类判定依据消息携带图片（QQ 发图/引用）数量。
- 子分类未配 LLM → 回退全局路由 LLM；未配模板 → 回退默认增强模板。
- 画面分析提示词 = 输出文本（ShowText）的工作流，暂无本地工作流，占位留空。
- 音频子分类同理占位留空。

## 3. 决策日志

| 决策 | 备选 | 原因 |
|------|------|------|
| 子分类判定 = 规则为主 + 手动指定（wf=/子类关键词） | 纯 LLM 判定 | 用户不信任 LLM 识别；带图/图数可用规则零幻觉判定 |
| 每子分类独立配置（工作流+LLM+模板） | 大类共享/全局一套 | 用户明确要求"单独安排子 LLM + 单独提示词" |
| 子分类清单 = 图片3 + 视频3 + 音频1（占位） | 只图+视频 | 用户确认 |
| 配置表驱动（方案 A） | 预设承载子类 / schema 写死 | 预设是给 LLM 的工具、路由配置是运维数据，分离维护；写死无法页面配置 |
| 图生类无图 → 自动降级对应文生类 | 报错 | 体验优先，不打断 |
| 产物直发 context.send_message | 依赖机器人 LLM 决定 | v4.27 工具运行器只缓存图片让 LLM「审核后发送」，经常不发 |
| UI 整体重做 | 局部修补 | 用户确认按专业标准重新设计 |

## 4. 最终设计

### 4.1 配置结构（插件配置，设置页管理）

```json
"subtype_configs": {
  "text2image":        { "label": "文生图",        "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "image2image":       { "label": "图生图",        "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "prompt_analysis":   { "label": "画面分析提示词", "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "text2video":        { "label": "文生视频",      "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "image2video":       { "label": "单图生视频",    "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "multi_image2video": { "label": "多图生视频",    "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" },
  "audio_gen":         { "label": "音频生成",      "workflow": "", "llm_provider": "", "llm_model": "", "prompt_template": "" }
}
```

- `workflow` 留空 = 子分类不可用（路由到时中文提示"请在设置页配置【文生图】工作流"）。
- `llm_provider`/`llm_model` 留空 = 回退全局路由 LLM。
- `prompt_template` 留空 = 默认增强模板；支持 `{policy}` 占位（NSFW 策略注入点）。
- 兼容迁移：现有 `default_workflows`（image/video/audio）→ 映射为对应子分类的 workflow。

### 4.2 子分类规则

| 预判 | 规则 |
|------|------|
| 图片数 > 1 | 多图类预选（video→multi_image2video；image→image2image 首图为主） |
| 图片数 == 1 | 单图类预选（video→image2video；image→image2image） |
| 无图 | 文生类预选（video→text2video；image→text2image） |
| 手动指定 | `wf=工作流名` 直接锁定工作流（跳过子类选择）；`subtype=xxx` 直接锁定子分类 |

一级 LLM 只输出 `{kind: image|video|audio|text}`，子分类由规则 + 预判确定。

### 4.3 流水线

```
用户消息（文字+图）
 → 预判（图数/手动指定）
 → 一级 LLM 分类 kind（全局路由 LLM；不可用→关键词规则）
 → 子分类 = 规则(预判, kind, 手动指定)
 → 查 subtype_configs[子分类]
 → 二级提示词分析（该子分类 LLM + 模板）→ 英文 tag 正/负
 → 自动注入（占位符或自动识别提示词框）→ 提交 ComfyUI
 → 产物去重 → 直发 QQ
```

### 4.4 降级链

1. 一级分类 LLM 不可用 → 关键词规则（图/画→image；视频→video；音乐/音频→audio；文本→text）。
2. 子分类工作流未配置 → 中文提示 + 建议相邻子分类。
3. 子分类 LLM 未配置 → 回退全局路由 LLM。
4. 子分类模板未配置 → 默认增强模板。
5. 二级增强失败 → 原始描述 + 默认负提示词。
6. 图生类没带图 → 降级对应文生类（image2image→text2image），回复中说明。
7. 直发失败 → 回退事件链旧行为。

### 4.5 UI 重做（Web 控制台 + 本地 GUI）

- **Web 设置页**：「🎯 子分类配置」卡片，7 行：子分类名徽标 → 工作流下拉（按识别类别过滤）→ LLM 下拉 → 模型输入 → 提示词模板（折叠）→ 恢复默认。现有「默认工作流」卡片并入。
- **Web 工作流页**：保留识别标签/徽标；单行布局更紧凑；切页暂停 LiteGraph 渲染（已修）。
- **本地 GUI**：状态区 + 进度条保留；配置表单按「隧道 / 子分类 / ComfyUI / 本地 LLM」分区重排；日志区保留。
- 设计令牌沿用 v3 体系（深色 + 渐变强调）。

## 6. UI 大换新设计（v0.3.0 UI 部分）

### 6.1 设计语言（Web + 本地统一）

- **风格**：深色高级感（VS Code / Linear 风）：细腻渐变光效、玻璃拟态卡片、克制的强调色、清晰的层级。
- **品牌**：两端都带 ☁️ 云信互联 Logo（Web 左上角 + 本地自绘标题栏）。

### 6.2 Web 控制台（云端）

- **布局**：左侧固定侧边栏导航（图标+文字），右侧内容区。
- **栏目（四区）**：概览（大状态卡 + 实时进度条 + 能力清单）/ 工作流（识别标签、图、上传删除）/ 预设 / 设置（含 🎯 子分类配置卡片）。

### 6.3 本地 GUI（YunxinAgent.exe）

- **自绘标题栏**：无边框窗口 + 品牌 Logo + 连接状态点 + 最小化/关闭按钮 + 可拖动。
- **左侧图标导航五区**：
  - 总览（自定义页）：可配置卡片网格——服务状态卡 / 资源监控卡 / 当前进度卡 / 最近任务卡
  - 配置：隧道 / 子分类 / ComfyUI / 多 LLM 服务表单
  - 历史：生成记录（时间/提示词/工作流/耗时/产物路径，双击打开产物文件夹）
  - 日志：搜索 / 级别过滤 / 导出
  - 设置：通知开关、自定义页卡片管理、开机自启
- **新增六项功能**：多服务状态总览（多个 Ollama/LM Studio/vLLM 实例）、系统资源监控（CPU/内存/GPU）、生成历史、完成桌面通知、日志搜索导出、可配置自定义页。
